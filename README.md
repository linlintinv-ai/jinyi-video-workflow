阶段 1：选题策划与反差 Hook

选题原则：每一期只讲透 1 个微小痛点或认知反常识（如“离火运误区”、“中女心肾不交”、“结节与情绪”）。


前 3 秒黄金法则：必须在前 3 秒抛出认知颠覆或直击痛点的问题，禁止任何无效铺垫。

阶段 2：结构化分镜头脚本编写
每个脚本必须严格输出 4 列字段：

1.
时间码（Timecode）：精确到秒（单条总时长建议 35～55 秒）。
2.
3.
画面形式（Shot Type）：明确标注是【数字人出镜】还是【B-Roll素材/图文快剪】。
4.
5.
视觉描述与文字卡（Visual Prompt）：画面提示词与屏幕大字幕。
6.
7.
完整口播词（Voiceover Script）：字数控制在 160～220 字之间。
8.
阶段 3：数字人出镜触发策略（严禁全屏长时间单帧）

触发场景：

o
开头 Hook（0~3秒）：数字人中景/半身出镜，眼神笃定，建立 IP 第一印象。
o
o
结尾 CTA（最后 5 秒）：数字人再次出镜引导关注与互动。
o
o
中段重点强调（可选）：以屏幕右下角小比例“画中画（PiP）”呈现，不遮挡主体教学图示。
o

非出镜场景：讲解原理、穴位图示、情绪故事时，画面全部切为意境空镜、文字动态卡点或实操动作。

阶段 4：音频基准与声音克隆

必须先生成全片单条无缝的完整配音音频，以此作为全片绝对时间线（Master Audio Timeline）。


语速标准：210～230 字/分钟，字句之间预留 0.3～0.5 秒呼吸气口。

阶段 5：素材与视觉生成

数字人镜头：使用固定机位的高清正脸/半身肖像基准图，通过 LivePortrait / MuseTalk 等技术驱动口型与微表情。


B-roll 风格：东方简约美学（青瓦白墙、清茶素案、晨光绿植、古籍特写），色调沉静柔和。

阶段 6：自动化对齐剪辑与压制

依赖 FFmpeg、CapCut CLI 或 MoneyPrinterTurbo 剪辑内核：

o
音频与字幕通过 Whisper / SRT 自动对齐；
o
o
预设 9:16 竖屏（1080×1920，30fps）；
o
o
背景音乐（BGM）：古典轻缓器乐（古琴、轻弦乐），音量控制在 -24dB，人声音量锁定在 -14~-16 LUFS。
o
